HENNA STUDIO - WINDOWS x64 - v15

1. Extract the entire ZIP to a writable folder, such as your Desktop.
2. Open that folder and double-click HennaStudio.exe.
3. Your browser opens http://127.0.0.1:8765. Keep the Studio console window open.
4. To stop Studio, press Ctrl+C in its console window.

Keep HennaStudio.exe, _internal and app together. Python installation is not needed.
If the address is already in use, stop the earlier Studio instance and try again.

YOUR FILES
  app/current_calibration.json and app/validation: approved machine calibration.
  app/designs: design gallery and uploaded SVG files.
  app/outputs: new jobs, previews, plans and programs.
  app/validation_log_S2026-10-05-A.csv: new validation log, initially header only.
  Your Windows Documents folder: camera recordings, as in the existing app.
Back up the app folder and your recordings. Keep your old source project too.
Extract future versions into a new folder; do not overwrite an app folder with jobs.

WORKFLOW
Studio does everything - no UGS. Close UGS and RealSense Viewer before starting.
1. Connect. Clear all hands and objects from the travel area, then Home and confirm.
2. Scan: Move to scan position, wait for Position ready, place the hand, Record scan.
3. Hand & region: check and accept the outline.
4. Design: choose, size, rotate and drag; nozzle 4 mm or more; Check on measured skin.
5. Program: written, then re-read by a separate checker.
6. Run: Start (four confirmations), Pause / Resume, STOP. Prosthetic hand only.
Jog (top bar): 0.1 / 1 / 10 mm steps after Home, always at Z -20 or higher.
Pause = hold (checked: if the machine keeps moving, Studio stops it). STOP = hold + reset: home again.
Any controller error stops the run.
The first real run is a machine validation test: run it once in the air, with NO hand.

motion_ready=false. Real-hand jobs support camera preview only; no programs or runs.
No dispensing. Calibration rules are unchanged (travel Z -20, feeds 300 / 1000).
Camera/controller USB drivers are external to this package.

This is a fresh app workspace. Previous jobs and recordings are not copied into it.
The Classic page is available at /classic; old pencil-practice calibration history
is not included. Current Studio calibration and hand model are included unchanged.

BUILD_MANIFEST.json identifies the source and dependencies. build_source contains
the launcher and build recipe. If included, VALIDATION.txt describes checks performed
on this build; building an executable alone does not validate the hardware.
